# React Google Apps Script Starter

A modern starter template for building **Google Apps Script Web Apps** using **React 19**, **Vite**, and **Google Sheets**.

Inspired by architecture patterns from production apps (`laporan-keuangan` and `reimbursement-app`).

---

## ✨ Features

- **⚡ Modern React 19 + Vite**: Fast build times, instant Hot Module Replacement (HMR).
- **📦 Single-File HTML Inlining**: Powered by `vite-plugin-singlefile`, all JavaScript, CSS, and SVG assets are bundled into a single standalone `index.html` compatible with `HtmlService.createHtmlOutputFromFile('index')`.
- **🔄 Dual Environment Support (Local Mock vs GAS)**:
  - **Local Development (`npm run dev`)**: Works directly in your browser with realistic mock data, simulated network latency, and live state mutations. No clasp deploy needed for UI changes!
  - **Google Apps Script Production**: Automatically detects the Google Apps Script runtime and routes calls to `google.script.run`.
- **📊 Real-World Google Sheets Integration**:
  - Auto-initializes and seeds sample data into your spreadsheet if the sheet is blank or missing.
  - Supports reading data rows mapped to JSON objects by header name.
  - Formats Dates (`Utilities.formatDate`), handles currency and quantities.
  - Supports adding new rows (`addItem`).
- **🎨 Beautiful & Responsive UI**:
  - Filter bar: Live search, category dropdown, status dropdown, reset filter.
  - View switcher: Toggle between responsive **Data Table** and **Grid Cards**.
  - Metric summary cards (Total records, asset valuation, stock levels).
  - Item detail modal & Add item modal.
  - Clean status pills (`In Stock`, `Low Stock`, `Out of Stock`).

## 🚀 Getting Started

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [Google Clasp](https://github.com/google/clasp) (optional, for automated deployments):
  ```bash
  npm install -g @google/clasp
  clasp login
  ```

### 2. Install Dependencies
```bash
npm install
```

### 3. Local Development
Run the local Vite development server:
```bash
npm run dev
```
Open `http://localhost:5173` in your browser. The app runs in **Local Mock Mode** (`⚡ [Local Dev] Using mock Google Sheet data`), allowing you to build and preview your UI rapidly with live data filters, search, and form additions.

## 🚢 Deploying to Google Apps Script

### Method 1: Using Google Clasp (Recommended)

1. Create a Google Spreadsheet or open an existing one.
2. In the Google Spreadsheet menu, navigate to **Extensions > Apps Script** to get your Script ID (from Project Settings ⚙️).
3. Create your `.clasp.json` from the example:
   ```bash
   cp .clasp.json.example .clasp.json
   ```
4. Replace `"YOUR_APPS_SCRIPT_ID_HERE"` with your actual Apps Script ID.
5. Build and push in one command:
   ```bash
   npm run build:push
   ```
6. In Google Apps Script, click **Deploy > New deployment**:
   - Type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (or your organization)
   - Click **Deploy** and open the Web App URL.

### Method 2: Manual Copy-Paste
If you don't use Clasp:
1. Run:
   ```bash
   npm run build
   ```
2. Open your Apps Script editor.
3. Paste the contents of `apps-script/Code.js` into your Apps Script `Code.gs` file.
4. Create an HTML file named `index.html` in Apps Script, and paste the entire contents of `apps-script/index.html` (or `dist/index.html`) into it.
5. Deploy as Web App.

## 🧩 How to Add New Sheet Functions

### 1. Add Backend Function (`apps-script/Code.js`)
```javascript
function getCustomSummary() {
  const sheet = getOrCreateSheet();
  // your custom logic...
  return jsonSuccess({ result: "my summary data" });
}
```

### 2. Call in React (`src/services/gasApi.js`)
```javascript
export async function getCustomSummary() {
  if (isGasEnvironment()) {
    return await callGasFunction("getCustomSummary");
  }
  
  // Local mock fallback:
  return {
    success: true,
    data: { result: "mock summary data" },
    isMock: true,
  };
}
```
